# ✅ Todo App

A simple, clean, and lightweight **Todo App** built with HTML, CSS, and JavaScript.

The application allows users to create and manage tasks, mark tasks as completed, filter tasks by their status, delete individual tasks, clear all completed tasks, and automatically save tasks in the browser.

---

## ✨ Features

- ➕ Add new tasks
- ⌨️ Add tasks using the Enter key
- ✅ Mark tasks as completed
- ↩️ Mark completed tasks as active again
- 🗑️ Delete individual tasks
- 🧹 Clear all completed tasks
- 📋 View all tasks
- 🔄 Filter tasks:
  - All
  - Active
  - Completed
- 🔢 Display the number of remaining tasks
- 📅 Display the current date
- 💾 Save tasks using browser Local Storage
- 🔁 Automatically restore tasks after refreshing the page
- 📭 Empty-state message when there are no tasks
- 📱 Clean and responsive interface
- ⚡ Lightweight and fast
- 🎨 Minimal modern design

# 🛠️ Built With

This project uses standard front-end web technologies:

- **HTML5** – Application structure
- **CSS3** – Styling, layout, animations, and visual states
- **JavaScript** – Task management and application logic
- **Local Storage API** – Persistent task storage
- **Font Awesome** – Interface icons
- **Browser Date API** – Current date display
